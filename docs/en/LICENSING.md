## Project description

Describe the current publication as **“free to use, source available, with noncommercial redistribution”**. A license restricting commercial redistribution does not meet the [Open Source Initiative's Open Source Definition](https://opensource.org/osd).

These terms do not cover manufacturer APKs collected by a diagnostic export. Such files are not distributed in this repository.
